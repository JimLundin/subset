# Keep the whole value a variant pattern matched

The original rule below is superseded in version 12 by
[0048](0048-pat.ident.at-and-grouping.md): an immutable `@` binding may wrap
every otherwise-permitted pattern, including grouped alternatives,
literals, tuples, and 0047's slice patterns.

## Rule
`name @ Pattern` is allowed when `Pattern` is a struct, tuple-struct or path
pattern, that is, a variant or struct, and the binding has no `mut` or
`ref`. It names the whole value an arm matched, so the arm can pass it on
without rebuilding it or cloning it before the match. `x @ 3`, `x @ 1..=9`
and `x @ (a, b)` stay outside: a literal is a guard-free pattern on its own,
and a tuple's parts are bound by name already.

## Before
`crates/daemon/src/session.rs` and `crates/client/src/link.rs`:

```rust
match event {
    Event::Open { id, peer } => self.open(Event::Open { id, peer }),
    Event::Closed => self.close(),
}
```

or a `.clone()` of the scrutinee taken before the match.

## After

```rust
match event {
    open @ Event::Open { .. } => self.open(open),
    Event::Closed => self.close(),
}
```

## Measurement
Two sites in the issue; each drops the rebuilt struct literal or the clone.
`tests/cases/ident-at` keeps the allowed and rejected forms.
