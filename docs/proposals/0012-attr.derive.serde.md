# serde derives on wire types

## Rule
`#[derive(Serialize, Deserialize)]` is allowed on a type that crosses a wire: the frames in `crates/proto`, and the provider protocol messages in `crates/agents`. `#[serde(...)]` is allowed with these keys only: `transparent`, `tag`, `content`, `rename_all`, `rename`. Other serde attributes (`default`, `skip`, `flatten`, `with`, `untagged`) need their own proposal.

## Before
No subset-only form exists. A hand-written `Serialize`/`Deserialize` impl needs generic visitor types and trait impls, and it runs to dozens of lines per type. 0009 allows it only where a derive can't express the shape. `crates/proto/src/lib.rs` has 19 derived wire types.

## After
```rust
// crates/proto/src/lib.rs
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
#[serde(transparent)]
pub struct Epoch(pub u64);

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "open", rename_all = "snake_case")]
pub enum Open {
    Hello(Hello),
    Subscribe(Subscribe),
    Command(Command),
    Rtc(RtcOffer),
}
```

Friction points removed: 51 sites: 19 `attr.derive.Serialize`, 19 `attr.derive.Deserialize` and 13 `attr.serde`. The 12 `macro.json` sites in `agents` become typed structs under this rule (§A13).

## Qualities
1. Named states: kept, and helped. The wire shape is a named Rust type, with no `Value` maps.
2. Visible branching: kept.
3. Forward data flow: kept.
4. Errors are values: kept. Decoding returns a `Result`.
5. Local reasoning: kept. The attributes on the type say how it is encoded.
6. One way: kept. One way to put a type on the wire.
