# Slice types `&[T]`

## Rule
`&[T]` is allowed as a parameter type wherever the function only reads a sequence, in place of `&Vec<T>`. It is also the type of a `const` byte string or list (`const ALPN: &[u8] = b"…"`). Since version 4 a constant list is always `const NAME: &[T] = &[..]`, never `[T; N]` (see the amendment below). `&mut [T]` is covered only by 0008(b), for read buffers.

## Before
Subset-only, with `&Vec<T>` (`examples.md` §8 and §9) and `Vec`-returning functions in place of constants:

```rust
pub fn alpn() -> Vec<u8> {
    Vec::from(b"conductor/0")
}
pub fn default_stun_servers() -> Vec<String> {
    Vec::from([String::from("stun:stun.l.google.com:19302"), String::from("stun:stun.cloudflare.com:3478")])
}

fn seqs(events: &Vec<Event>) -> Vec<u64> {
    events.iter().map(|e| e.seq.0).collect()
}

fn transcript(events: &Vec<Event>) -> String {
    events.iter().filter_map(|e| match &e.kind {
        EventKind::TranscriptDelta { text } => Some(text.as_str()),
        _ => None,
    }).collect()
}

fn decode(body: &Vec<u8>) -> Result<Open, FrameError> {
    serde_json::from_slice(body).map_err(FrameError::Json)
}
```

## After
From `crates/proto/src/lib.rs`, `crates/daemon/tests/e2e.rs` and `crates/proto/src/frame.rs`:

```rust
pub const ALPN: &[u8] = b"conductor/0";
pub const DEFAULT_STUN_SERVERS: &[&str] = &["stun:stun.l.google.com:19302", "stun:stun.cloudflare.com:3478"];

fn seqs(events: &[Event]) -> Vec<u64> {
    events.iter().map(|e| e.seq.0).collect()
}

fn transcript(events: &[Event]) -> String {
    events.iter().filter_map(|e| match &e.kind {
        EventKind::TranscriptDelta { text } => Some(text.as_str()),
        _ => None,
    }).collect()
}

fn decode(body: &[u8]) -> Result<Open, FrameError> {
    serde_json::from_slice(body).map_err(FrameError::Json)
}
```

The subset-only form also fails the gate. `cargo clippy -- -D warnings` (`tools/check.sh`) rejects every `&Vec<T>` parameter with `clippy::ptr_arg`. I checked this on a scratch crate with the same toolchain, and the error was `writing &Vec instead of &[_] involves a new object where a slice will do`. `examples.md` §8 and §9 fail clippy as written.

Friction points removed: 14 `type.slice` sites in 7 files, plus the two examples in `examples.md`, which become correct.

## Qualities
1. Named states: kept.
2. Visible branching: kept.
3. Forward data flow: kept. A shared slice is read-only.
4. Errors are values: kept.
5. Local reasoning: kept.
6. One way: kept, and helped. One way to take a sequence, the one clippy enforces.

## Owner decision
Accepted on 2026-11-11, with the rest of the bootstrap round.

Amended on 2026-11-11, in subset version 4. A constant list has one form, `const NAME: &[T] = &[..]`, so no one counts its length by hand. 0015(b)'s `const` tables move to this form, and `[T; N]` stays only for 0015(a). The checker now accepts the `&[..]` initializer, which it used to flag as `expr.array` (the proto review's tool fix).
