# `async fn`, `.await` and async blocks

## Rule
`async fn` is allowed for a function that does I/O, waits on a channel or a timer, or calls one that does. `.await` is allowed on such calls. An `async` block (`async move { … }`) is allowed only (a) as the direct argument of a spawn call (`tokio::spawn`, `n0_future::task::spawn`, Dioxus `spawn`), or (b) as the whole body of a closure passed to a stream constructor or adapter (`stream::unfold`, `StreamExt::then`) or to Dioxus `use_future`. `#[tokio::main]` is allowed on `fn main` of a native binary. An async block used as a `try` block (`let r: Result<…> = async { … }.await`) is not allowed. Write a separate `async fn` instead.

## Before
No subset-only form exists. Without `async`, the only way to wait is a hand-written `Future` impl. That needs a trait impl, `Pin<&mut Self>`, `Context` and `poll`, none of which is in the subset, and each is longer than the async fn it replaces. The architecture is async throughout: iroh, tokio processes and channels, and str0m driven by tokio sockets (`docs/architecture.md` §5, §7, §8).

## After
```rust
// crates/agents/src/claude/session.rs
pub async fn send_user(&self, text: String) -> Result<()> {
    self.request(|reply| CommandMsg::SendUser { text, reply })
        .await?
}

// crates/agents/src/claude/session.rs, case (a)
tokio::spawn(async move {
    let mut lines = BufReader::new(stderr).lines();
    while let Ok(Some(line)) = lines.next_line().await {
        tracing::warn!(target: "claude::stderr", "{line}");
    }
});
```

## Qualities
1. Named states: kept. A future is a value of a named type.
2. Visible branching: kept. `.await` suspends the task. It does not branch.
3. Forward data flow: kept. Awaiting does not mutate our values.
4. Errors are values: kept. Async fns return `Result` like any other.
5. Local reasoning: kept. The `async` keyword in the signature tells the reader the function waits. The narrow block rule keeps async bodies visible as named functions.
6. One way: kept. One idiom for waiting. Spawned work is either an async fn call or a block in a spawn call.
