# Wire types take the shape their protocol fixes

## Rule
In the files where serde derives are allowed (0012's scope):

- `#[serde(untagged)]` may stand on an enum, for messages a protocol tells
  apart by shape rather than by a tag.
- `#[serde(skip_serializing_if = "Option::is_none")]` may stand on a field,
  for a protocol that omits an absent field rather than sending `null`. No
  other predicate.
- A field of a struct or enum variant that derives `Serialize` or
  `Deserialize` may be a `bool`, and `true` / `false` may be the value of
  such a field wherever the struct is built.

This is 0023's boundary applied to serde types: the shape is fixed by a
protocol we don't define, so a `bool` there is the protocol's, not a state
of ours. It stops at the wire type: a `bool` read from one becomes an enum
before it flows into our own types, as 0019 asks of a clap flag.

## Before
From `crates/agents/src/{claude,codex}/protocol.rs`, where outbound JSON has
to match the vendored SDKs byte for byte:

```rust
// A struct per shape, so an absent field is omitted rather than null.
#[derive(Serialize)]
struct Envelope { id: RequestId, result: Reply }
#[derive(Serialize)]
struct EnvelopeWithInterrupt { id: RequestId, result: Reply, interrupt: Interrupt }

// The CLI's `interrupt: true` as a two-variant enum serialised to a bool.
enum Interrupt { DenyAndInterrupt }

// JSON-RPC messages told apart by hand.
fn classify(value: serde_json::Value) -> Message { .. }
```

## After

```rust
#[derive(Serialize, Deserialize)]
struct Envelope {
    id: RequestId,
    result: Reply,
    #[serde(skip_serializing_if = "Option::is_none")]
    interrupt: Option<bool>,
}

#[derive(Deserialize)]
#[serde(untagged)]
enum Message {
    Response(Response),
    Error(ErrorResponse),
    Request(Request),
    Notification(Notification),
}
```

## Measurement
The issue lists seven sites in the two protocol modules, each a duplicated
struct, a hand-written match over `serde_json::Value`, or a bool-carrying
enum; the after form removes the duplicate types and the `Value` matching.
`tests/cases/serde-wire` keeps the allowed and rejected forms.
