# Keep a whole value while matching any permitted shape

## Rule

An immutable `name @ Pattern` may wrap any pattern already permitted by
the subset. The outer name has neither `mut` nor `ref`. Parentheses group
patterns without changing the rules on their contents:

```rust
n @ 3
n @ (1 | 2)
pair @ (a, b)
event @ (Event::Opened { .. } | Event::Updated { .. })
whole @ _
bytes @ ([0x01, _, _] | [0x02, _, _])
[first, remaining @ ..]
```

The rest example uses 0047's slice-only rest rule. Range patterns were
outside at acceptance; version 13 adds integer/character ranges under
[0049](0049-pat.range.md). Boolean patterns, explicit reference patterns,
and tuple/tuple-struct rests remain outside. Grouping or `@` does not make
prohibited patterns permitted. Alternative branches
must bind compatible names and types, as required by Rust.

## Before and after

Conductor #5's `log.rs` example wanted two live-only event alternatives to
share an arm while retaining the original event:

```rust
match event {
    event @ (Event::AssistantDelta { .. } | Event::AssistantMessage { .. }) => live(event),
    other => remaining(other),
}
```

This removes the restriction in 0044 that limited the inner pattern to a
struct, tuple-struct, or path. The owner explicitly selected literals,
grouped alternatives, tuple destructuring, and every other permitted
pattern, beyond the report's event example.

## Qualities

1. **Named states: kept.** The binding preserves the existing domain value.
2. **Visible branching: kept.** Alternatives appear in one pattern.
3. **Forward data flow: kept.** The outer binding is immutable.
4. **Errors are values: kept.** Other cases stay explicit arms.
5. **Local reasoning: kept.** Selection and retention share one pattern.
6. **One way: kept.** Retain the matched value with `@` instead of
   reconstructing it or cloning the scrutinee before selection.
7. **Repetition is data: kept.** Related alternatives can share an arm.

## Enforcement and limits

The checker checks outer binding modifiers and visits every inner pattern
normally. Rust checks whether retaining the whole value is compatible
with destructuring its fields. `pair @ (a, b)` works for copied fields;
moving `String` fields while retaining their owned tuple fails to compile.
Borrowed matching also supports shared views under Rust's match ergonomics.

CLI fixtures cover accepted forms, nested bindings, grouping, and attempts
to hide prohibited patterns. Compilation tests cover the positive forms
and the ownership failure. This admits no new mutation or pattern kinds
beyond 0047's slice patterns and grouping.

## Owner decision

The owner selected every otherwise-permitted pattern, with an immutable
outer binding, on 2026-11-13. Implemented as version 12 alongside 0047.

Version 13 adds ranges (0049); version 14 adds shared-reference patterns,
