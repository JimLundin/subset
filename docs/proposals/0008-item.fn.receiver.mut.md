# Mutation owned by a loop

## Rule
Mutation is allowed in two places only. (a) **Loop state.** A function with a 0007 loop may take `mut self` or declare one `let mut` state binding just before the loop. That state's own methods, called from the loop, may take `&mut self` and assign to `self.field`. (b) **External `&mut` APIs.** A value of a type from outside our crates whose method takes `&mut self` may be bound with `let mut` or a `mut` pattern, and passed as `&mut x` to that method. This covers I/O handles, channel receivers, pinned futures, str0m's `Rtc` and read buffers. No other function takes a `&mut` parameter of our own types. Compound assignment (`+=`) is not allowed anywhere: write `x = x.checked_add(1)?`. Interior mutability (`Cell`, `RefCell`, atomics, `Mutex`) stays out.

## Before
The host actor (`crates/daemon/src/host.rs`) in subset-only form. It is a fold over the inbox. Every message returns a new `Actor` (it needs 0004), and every change to a `Vec` or `HashMap` rebuilds it through an iterator.

```rust
impl Actor {
    async fn run(self, inbox: mpsc::Receiver<Msg>, host: Host) {
        ReceiverStream::new(inbox)
            .fold(self, |actor, msg| ready(actor.on(msg, &host)))
            .await;
    }

    fn on(self, msg: Msg, host: &Host) -> Actor {
        match msg {
            Msg::Welcome { reply } => {
                drop(reply.send(self.welcome()));
                self
            }
            Msg::Subscribe { after_seq, reply } => {
                drop(reply.send(self.subscription(after_seq)));
                self
            }
            Msg::Command { body, by, reply } => {
                let (actor, result) = self.command(body, by, host);
                drop(reply.send(result));
                actor
            }
            Msg::Emit(kind) => self.emit(kind),
            Msg::OpenApproval { tool, detail, decided } => {
                let id = RequestId(self.next_request);
                let approvals = with(self.approvals, id, Approval::Open(decided));
                Actor { approvals, next_request: self.next_request.saturating_add(1), ..self }
                    .append(EventKind::ApprovalRequested { id, tool, detail })
            }
        }
    }

    fn emit(self, kind: EventKind) -> Actor {
        let turn = match &kind {
            EventKind::TurnFinished => Turn::Idle,
            _ => self.turn,
        };
        Actor { turn, ..self }.append(kind)
    }

    fn append(self, kind: EventKind) -> Actor {
        let event = Event { seq: self.head().next(), kind };
        drop(self.live.send(event.clone()));
        let log = self.log.into_iter().chain(std::iter::once(event)).collect();
        Actor { log, ..self }
    }

    fn resolve(self, approval: RequestId, decision: Decision, by: String) -> (Actor, CommandResult) {
        let (found, rest) = split_off(self.approvals, approval);
        match found.into_values().next() {
            None => (Actor { approvals: rest, ..self }, CommandResult::Rejected(Rejection::UnknownApproval)),
            Some(Approval::Resolved { by: first }) => {
                let approvals = with(rest, approval, Approval::Resolved { by: first.clone() });
                (Actor { approvals, ..self }, CommandResult::Rejected(Rejection::AlreadyResolved { by: first }))
            }
            Some(Approval::Open(open)) => {
                let approvals = with(rest, approval, Approval::Resolved { by: by.clone() });
                let actor = Actor { approvals, ..self }
                    .append(EventKind::ApprovalResolved { id: approval, decision, by });
                drop(open.send(decision));
                (actor, CommandResult::Accepted)
            }
        }
    }
}

fn with(approvals: HashMap<RequestId, Approval>, id: RequestId, approval: Approval) -> HashMap<RequestId, Approval> {
    approvals.into_iter().chain(std::iter::once((id, approval))).collect()
}

fn split_off(approvals: HashMap<RequestId, Approval>, id: RequestId) -> (HashMap<RequestId, Approval>, HashMap<RequestId, Approval>) {
    approvals.into_iter().partition(|(key, _)| key.eq(&id))
}
```

## After
The same actor under the rule. The state is `mut self` in `run` and `&mut self` in the methods it calls.

```rust
impl Actor {
    async fn run(mut self, mut inbox: mpsc::Receiver<Msg>, host: Host) -> Result<Infallible, Stopped> {
        loop {
            let msg = inbox.recv().await.ok_or(Stopped {})?;
            self.on(msg, &host);
        }
    }

    fn on(&mut self, msg: Msg, host: &Host) {
        match msg {
            Msg::Welcome { reply } => drop(reply.send(self.welcome())),
            Msg::Subscribe { after_seq, reply } => drop(reply.send(self.subscription(after_seq))),
            Msg::Command { body, by, reply } => {
                let result = self.command(body, by, host);
                drop(reply.send(result));
            }
            Msg::Emit(kind) => self.emit(kind),
            Msg::OpenApproval { tool, detail, decided } => {
                let id = RequestId(self.next_request);
                self.next_request = self.next_request.saturating_add(1);
                self.approvals.insert(id, Approval::Open(decided));
                self.append(EventKind::ApprovalRequested { id, tool, detail });
            }
        }
    }

    fn emit(&mut self, kind: EventKind) {
        match &kind {
            EventKind::TurnFinished => self.turn = Turn::Idle,
            _ => {}
        }
        self.append(kind);
    }

    fn append(&mut self, kind: EventKind) {
        let event = Event { seq: self.head().next(), kind };
        self.log.push(event.clone());
        drop(self.live.send(event));
    }

    fn resolve(&mut self, approval: RequestId, decision: Decision, by: String) -> CommandResult {
        match self.approvals.remove(&approval) {
            None => CommandResult::Rejected(Rejection::UnknownApproval),
            Some(Approval::Resolved { by: first }) => {
                self.approvals.insert(approval, Approval::Resolved { by: first.clone() });
                CommandResult::Rejected(Rejection::AlreadyResolved { by: first })
            }
            Some(Approval::Open(open)) => {
                self.approvals.insert(approval, Approval::Resolved { by: by.clone() });
                self.append(EventKind::ApprovalResolved { id: approval, decision, by });
                drop(open.send(decision));
                CommandResult::Accepted
            }
        }
    }
}
```

The subset-only version also costs time. `append` copies the whole event log on every event, and the log grows without bound, so a host that has logged n events does O(n²) work. `resolve` partitions the whole approvals map for each lookup. Part (b) has no subset-only form at all: `mpsc::Receiver::recv`, `AsyncWriteExt::write_all`, `Lines::next_line` and every str0m `Rtc` method take `&mut self`.

Friction points removed: 374 sites considered, 132 `stmt.let.mut`, 71 `expr.assign`, 63 `item.fn.receiver.mut`, 57 `expr.reference.mut`, 31 `type.reference.mut` and 20 `pat.ident.mut`. The rule admits the ones inside actors and at external APIs. The rest (accumulators, counters, `&mut Turn` parameters in the bins, `&mut failures` in `link.rs`) are rejected and get the shapes in the review's §C2.

Of all the proposals, this one weakens a quality the most. It is here because the alternative is a subset-only actor that is longer, much slower and harder to read. Part (b) has no alternative at all.

## Qualities
1. Named states: kept. State is still a named struct, and the rule forbids flags kept on the side.
2. Visible branching: kept.
3. Forward data flow: weakened, and confined. Inside an actor, a method changes `self` instead of returning a new value. Rust's exclusive `&mut` means no other code observes the change, so the actor's state is as local as a value threaded through a fold. Outside an actor and external APIs, the quality holds in full. The owner should decide this one knowingly.
4. Errors are values: kept.
5. Local reasoning: kept. All mutation of our types sits in one struct's methods, called from one loop.
6. One way: kept. One place for state that changes over time, the actor. Every other function builds values.
