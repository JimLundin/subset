# Arrays

## Rule
Arrays are allowed in three places. (a) Fixed-size byte values whose size is part of a format or an external API (`[u8; 32]` keys, `[u8; 16]` tokens, frame headers, STUN transaction ids), including the repeat form `[0u8; N]` for a buffer. (b) A `const` table (`const STUN_SCHEDULE: [Duration; 4]`). (c) A literal list passed straight to a function or method (`.args(["init", "-q"])`, `Vec::from([a, b])`). `vec![…]` becomes `Vec::from([…])`. Indexing stays out (§A7).

## Before
Subset-only: lists built from `iter::once` chains, and byte keys as `Vec<u8>` checked at runtime (`crates/daemon/src/rtc.rs`, `crates/agents/src/bin/s1.rs`, `crates/daemon/src/lib.rs`, `crates/agents/tests/replay.rs`):

```rust
fn stun_schedule() -> Vec<Duration> {
    std::iter::once(Duration::ZERO)
        .chain(std::iter::once(Duration::from_millis(250)))
        .chain(std::iter::once(Duration::from_millis(750)))
        .chain(std::iter::once(Duration::from_millis(1750)))
        .collect()
}

fn git_init(scratch: &Path) -> std::io::Result<ExitStatus> {
    Command::new("git")
        .args(std::iter::once("init").chain(std::iter::once("-q")))
        .current_dir(scratch)
        .status()
}

fn secret_key(bytes: Vec<u8>) -> Option<SecretKey> {
    bytes.try_into().ok().map(|bytes| SecretKey::from_bytes(&bytes))
}

fn options(claude: PathBuf) -> ClaudeOptions {
    ClaudeOptions {
        setting_sources: Some(
            std::iter::once(SettingSource::Project)
                .chain(std::iter::once(SettingSource::Local))
                .collect(),
        ),
        ..ClaudeOptions::new(claude)
    }
}
```

## After
```rust
const STUN_SCHEDULE: [Duration; 4] = [
    Duration::ZERO,
    Duration::from_millis(250),
    Duration::from_millis(750),
    Duration::from_millis(1750),
];

fn git_init(scratch: &Path) -> std::io::Result<ExitStatus> {
    Command::new("git").args(["init", "-q"]).current_dir(scratch).status()
}

fn secret_key(bytes: [u8; 32]) -> SecretKey {
    SecretKey::from_bytes(&bytes)
}

fn options(claude: PathBuf) -> ClaudeOptions {
    ClaudeOptions {
        setting_sources: Some(Vec::from([SettingSource::Project, SettingSource::Local])),
        ..ClaudeOptions::new(claude)
    }
}
```

## Qualities
1. Named states: kept, and helped. A key's length is in its type.
2. Visible branching: kept.
3. Forward data flow: kept. Writing into a repeat buffer goes through 0008(b).
4. Errors are values: kept. Without indexing, reads are `get` and `try_into`, which return `Option`/`Result`.
5. Local reasoning: kept.
6. One way: kept. One literal-list form, and `vec!` goes.
