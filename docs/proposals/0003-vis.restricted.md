# `pub(crate)` visibility

## Rule
`pub(crate)` marks an item or field that another module of the same crate uses and that is not part of the crate's API. `pub(super)` and `pub(in path)` are not allowed. A field of a `pub(crate)` struct is `pub(crate)` too, never `pub`.

## Before
Written with `pub` only (proposal 0002). The modules are private, so nothing leaks, but the item does not say so.

```rust
pub enum Inbound {
    Event(ClaudeEvent),
    ControlResponse { request_id: String, outcome: Result<Value, String> },
    UnsupportedControlRequest { request_id: String, subtype: String },
}
pub fn parse_line(line: &str) -> serde_json::Result<Inbound> { todo() }
pub struct UnsupportedVersion {
    pub found: String,
    pub supported: String,
}
pub fn check_version(initialize: Value) -> Result<(), UnsupportedVersion> { todo() }
pub enum ControlCall { Initialize, Interrupt, SetPermissionMode(PermissionMode) }
impl ControlCall {
    pub fn subtype(&self) -> &str { todo() }
}
pub fn encode(msg: Outbound) -> serde_json::Result<String> { todo() }
```

## After
From `crates/agents/src/claude/protocol.rs`, bodies elided.

```rust
pub(crate) enum Inbound {
    Event(ClaudeEvent),
    ControlResponse { request_id: String, outcome: Result<Value, String> },
    UnsupportedControlRequest { request_id: String, subtype: String },
}
pub(crate) fn parse_line(line: &str) -> serde_json::Result<Inbound> { todo() }
pub(crate) struct UnsupportedVersion {
    pub(crate) found: String,
    pub(crate) supported: String,
}
pub(crate) fn check_version(initialize: Value) -> Result<(), UnsupportedVersion> { todo() }
pub(crate) enum ControlCall { Initialize, Interrupt, SetPermissionMode(PermissionMode) }
impl ControlCall {
    pub(crate) fn subtype(&self) -> &str { todo() }
}
pub(crate) fn encode(msg: Outbound) -> serde_json::Result<String> { todo() }
```

The construct adds 3 tokens per item. It is proposed on meaning, not volume: with `pub` only, a reader has to check every `mod` line and `pub use` up to the crate root to learn whether an item is API.

Friction points removed: none by volume. 26 sites in 6 files. The real code also mixes the two forms (`pub(crate) struct UnsupportedVersion { pub found, pub supported }`), which the rule removes.

If the owner prefers one keyword, reject 0003 and keep 0002. Then `unreachable_pub` can't be enabled, because every crate-internal item would be `pub`.

## Qualities
1. Named states: kept.
2. Visible branching: kept.
3. Forward data flow: kept.
4. Errors are values: kept.
5. Local reasoning: kept, and helped. The item states its reach without a trip to `lib.rs`.
6. One way: kept. `pub` means the crate's API and `pub(crate)` means shared inside the crate. Each meaning has one spelling. Without 0003, `pub` means both.
