# A library visitor is a library hook

## Rule
`impl<'ast> Visit<'ast> for T` joins 0009's list, beside iroh's
`ProtocolHandler`: syn walks the tree and calls our code at each node, as a
framework calls a handler. The lifetime it demands is allowed in the impl,
as 0009 allows any a listed trait's signature demands.

A type that implements `Visit` is treated as one of 0035's endpoints: the
library's API takes it by `&mut self`, so its own helper methods may take
`&mut self`, and the one `let mut` that builds it before `visit_file` may
hold it. Everything else of 0008 holds: no `&mut` parameter of our types,
no compound assignment, and other types keep value-returning methods.

## Before
The checker written without the trait (this repository at the rewrite's
first pass): one explicit fn per syntax node kind, each listing its
children and the context each stands in.

```rust
fn method_call(m: &ExprMethodCall, node: Extent, cx: &Cx, base: &Cx, env: &Env, attrs: Vec<Hit>) -> Vec<Hit> {
    ..
    join(Vec::from([
        Vec::from([id(m.method.span(), node, "expr.method_call", env)]),
        adapter.into_iter().collect(),
        checks::method(m, cx, env),
        attrs,
        expr(m.receiver.as_ref(), &receiver_cx, env),
        m.turbofish.iter().flat_map(|t| t.args.iter().flat_map(|a| walk::generic_arg(a, base, base, env))).collect(),
        m.args.iter().flat_map(|a| expr(a, &arg_cx, env)).collect(),
    ]))
}
```

plus a table of every expression kind's attributes, and the same for every
item, type and pattern kind.

## After
One visitor overrides only the nodes that carry an id or a rule; syn
visits the children, which read the slot their parent gave them by their
extent.

```rust
impl<'ast> Visit<'ast> for Walk {
    fn visit_expr_field(&mut self, e: &'ast ExprField) {
        self.id(e.dot_token.span, e.span(), "expr.field");
        visit::visit_expr_field(self, e);
    }
}
```

## Measurement
`subset measure` on the walk, before and after, with the same 82 golden
cases passing:

| | tokens | lines |
|---|---|---|
| explicit walk (`walk.rs` + `exprs.rs`) | 22,912 | 2,479 |
| `Visit` walk (`walk.rs`) | 16,743 | 1,689 |

-27% tokens, -32% lines. The visit order also becomes syn's, the order the
checker's output was defined in before the rewrite.
