# Async tests

## Rule
`#[tokio::test]` is allowed in place of `#[test]` on an `async fn` test, with no arguments. Tests follow `examples.md` §14: they compare values with `assert_eq!`/`assert_ne!`. `assert!`, `panic!`, `unreachable!` and `matches!` stay out of tests too (see the review's §C3).

## Before
No subset-only form exists short of building a runtime in every test (`tokio::runtime::Runtime::new()?.block_on(…)`). That also needs `()` (0005), and it repeats the same three lines in each of the 16 async tests.

## After
```rust
// crates/agents/tests/replay.rs, with the C3 shape
#[tokio::test]
async fn unsupported_cli_version_is_refused() {
    let stdout = recording("future-cli", &[FUTURE_CLI]);
    let (claude, _) = fake_claude("future-cli", &stdout);
    let refused = ClaudeSession::spawn(options(claude)).await.err().map(|e| e.to_string());
    assert_eq!(
        refused.as_deref(),
        Some("claude 2.2.0 is not supported (supported: 2.1.316 to 2.1.322); set allow_untested_version to run it anyway")
    );
}
```
