# A match guard that compares two values

## Rule
A `match` arm may have a guard whose body is one comparison (`==`, `!=`,
`<`, `<=`, `>`, `>=`) or one `matches!`, with no `&&`, `||` or `!`. Use it
when the arm depends on a value its pattern bound being equal to, or
ordered against, another value in scope. A guarded arm is always followed
by an arm that covers the same pattern without the guard. Wrapping a single
value in an `Option` only to compare it (`Some(x).filter(|x| x.a == b)`) is
then not the form: `filter` and the other predicate adapters keep
collections and options that already exist.

This reopens one exclusion in 0028, which listed "a `match` guard" among
the places a boolean expression stays out. 0028 was decided on counting,
before any code needed a guard. Unit 3 shows four sites in one change.

## Qualities
1. Named states: kept. The comparison reads two named fields, and its
   `bool` never becomes a binding, field or return value.
2. Visible branching: kept, at the edge. Each arm is written out, and the
   rule requires the unguarded arm for the same pattern after the guarded
   one, so the "not equal" case is a visible arm, as the `None` arm is
   today. Rust's exhaustiveness check ignores guarded arms, which is why the
   rule makes the fallback arm explicit rather than leaving it to `_`.
3. Forward data flow: kept.
4. Errors are values: kept. `authenticate` still returns the refusal as an
   `Err` value.
5. Local reasoning: kept. The condition sits on the arm it selects, where
   today it sits in an `Option` built inside the arm's body.
6. One way: kept, with the rule's second sentence. Choosing an arm by
   equality is a guard; selecting from an existing collection or `Option`
   is a predicate adapter. Today one equality has two spellings in this
   diff (`Some(x).filter(..)` and `x.eq(y).then_some(..)`).
7. Repetition is data: kept.

## Tool change
`tools/subset` allows `expr.match.guard` whose expression is one comparison
or one `matches!`, and allows that comparison as it allows a predicate
body. It flags `Some(<expr>).filter(..)` where the `Option` is built at the
call, and a guarded arm with no later arm covering the same pattern is a
review check.
