# clap derives for command lines

## Rule
In a binary's `main.rs` and in `examples/`, a struct may derive `clap::Parser` and an enum may derive `clap::Subcommand` or `clap::ValueEnum`, with `#[command(...)]` and `#[arg(...)]` attributes. A choice between named values is a `ValueEnum`, never a string with `value_parser = [...]`. A `bool` field is allowed only for an on/off flag in such a struct. `main` converts it to a two-variant enum before passing it on, so `bool` never reaches library code.

## Before
Subset-only: the headless example's arguments parsed by hand (`crates/client/examples/headless.rs`). It still lacks `--help`.

```rust
struct Args {
    ticket: Ticket,
    prompt: String,
    decision: Decision,
    /// Drop the connection after this many transcript deltas of our turn,
    /// to show the resubscribe with `after_seq`.
    reconnect_after: Option<usize>,
    timeout_secs: u64,
}

const USAGE: &str = "usage: headless <ticket> [--prompt TEXT] [--decision approve|deny] [--reconnect-after N] [--timeout-secs N]";

impl Args {
    fn new(ticket: Ticket) -> Args {
        Args {
            ticket,
            prompt: String::from("what is the answer?"),
            decision: Decision::Approve,
            reconnect_after: None,
            timeout_secs: 60,
        }
    }

    fn parse(words: &[String]) -> Result<Args, String> {
        let (ticket, flags) = words.split_first().ok_or(String::from(USAGE))?;
        let ticket = Ticket::parse(ticket).map_err(|e| format!("ticket: {e}"))?;
        flags.chunks(2).try_fold(Args::new(ticket), |args, pair| {
            match (pair.first().map(String::as_str), pair.get(1)) {
                (Some("--prompt"), Some(value)) => Ok(Args { prompt: value.clone(), ..args }),
                (Some("--decision"), Some(value)) => {
                    decision(value).map(|decision| Args { decision, ..args })
                }
                (Some("--reconnect-after"), Some(value)) => value
                    .parse()
                    .map(|n| Args { reconnect_after: Some(n), ..args })
                    .map_err(|e| format!("--reconnect-after: {e}")),
                (Some("--timeout-secs"), Some(value)) => value
                    .parse()
                    .map(|n| Args { timeout_secs: n, ..args })
                    .map_err(|e| format!("--timeout-secs: {e}")),
                (flag, _) => Err(format!("unknown or incomplete flag {flag:?}\n{USAGE}")),
            }
        })
    }
}

fn decision(value: &str) -> Result<Decision, String> {
    match value {
        "approve" => Ok(Decision::Approve),
        "deny" => Ok(Decision::Deny),
        other => Err(format!("--decision must be approve or deny, not {other}")),
    }
}
```

## After
```rust
#[derive(Parser)]
struct Args {
    ticket: Ticket,
    #[arg(long, default_value = "what is the answer?")]
    prompt: String,
    #[arg(long, value_enum, default_value = "approve")]
    decision: DecisionArg,
    /// Drop the connection after this many transcript deltas of our turn,
    /// to show the resubscribe with `after_seq`.
    #[arg(long)]
    reconnect_after: Option<usize>,
    #[arg(long, default_value_t = 60)]
    timeout_secs: u64,
}

#[derive(Clone, Copy, ValueEnum)]
enum DecisionArg {
    Approve,
    Deny,
}
```

Friction points removed: 17 sites: 12 `attr.arg`, 2 `attr.command`, 2 `attr.derive.Parser` and 1 `attr.derive.Subcommand`. It also fixes `headless.rs`'s `_ => Decision::Deny`, which hides a decision behind a string match.

## Qualities
1. Named states: kept, and helped by `ValueEnum`. The flag `bool` is the one exception, and it stops at `main`.
2. Visible branching: kept.
3. Forward data flow: kept.
4. Errors are values: kept. clap reports bad input as an error value before `main` continues.
5. Local reasoning: kept. The struct is the command line's documentation.
6. One way: kept. One way to read arguments.
