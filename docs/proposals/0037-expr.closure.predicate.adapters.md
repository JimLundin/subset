# `rfind` and `wait_for` take predicate closures

## Rule
Amends 0028. Two names join the list of methods whose closure argument may have a boolean expression as its body: `rfind` (the iterator method) and `wait_for` (tokio's `watch::Receiver::wait_for`). Nothing else changes.

## Before
`crates/client/src/platform/rtc.rs:93`, `:94`, `:175`, `:463` and `:594`.

```rust
_ = peer.wait_for(|peer| Peer::Lost.eq(peer)) => {}
_ = liveness.wait_for(|state| ChannelState::Closed.eq(state)) => {}
_ = lost.wait_for(|peer| Peer::Lost.eq(peer)) => Err(String::from("the connection failed")),
let nominated = stats.iter().rev().find(|stat| matches!(..));
state.wait_for(|state| ChannelState::Connecting.ne(state))
```

## After
```rust
_ = peer.wait_for(|peer| peer == &Peer::Lost) => {}
_ = liveness.wait_for(|state| state == &ChannelState::Closed) => {}
_ = lost.wait_for(|peer| peer == &Peer::Lost) => Err(String::from("the connection failed")),
let nominated = stats.iter().rfind(|stat| matches!(..));
state.wait_for(|state| state != &ChannelState::Connecting)
```

Scratch files: `docs/subset/measurements/client-review/0037/before.rs` and `after.rs`.

## Weight
tolerated, the tier of 0028's predicate bodies. Boundary use: applies to `wait_for`, whose signature (`FnMut(&T) -> bool`) tokio fixes. It doesn't apply to `rfind`.

The after score counts the new predicate bodies as tolerated. The score rises because `.eq(..)` is a neutral method call and `==` in a predicate is tolerated.

Friction points removed: 5 of one kind (B2's four `wait_for` sites, and the `rfind` that clippy's `filter_next` asks for).

## Qualities
1. Named states: kept. The states compared are still enum variants.
2. Visible branching: kept. The adapter is the branch, as in 0028.
3. Forward data flow: kept.
4. Errors are values: kept.
5. Local reasoning: kept.
6. One way: kept, and helped. Today a predicate is written `a == b` inside `filter` and `B.eq(a)` inside `wait_for`. The checker accepts the `wait_for` closure only because it doesn't check whose method takes it; 0028's text names only iterator, `Option` and `Result` methods. After this, both read alike, and the spec covers the code that already exists.
7. Repetition is data: kept.

This proposal pays in consistency, not in volume. The owner may prefer to leave it until another crate adds sites.
