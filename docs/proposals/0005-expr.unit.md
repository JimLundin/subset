# The unit type `()`

## Rule
`()` is allowed as a type in `Result<(), E>`, as the item type of a channel or future that only signals (`oneshot::Sender<()>`, `watch::channel(())`), and in the return type of `fn main`. `()` as a value is allowed only as `Ok(())` and as the pattern `()` in a `select!` arm. A function that finishes with nothing to report returns `Result<(), E>` or no return type, never a `()` field or variable.

## Before
Subset-only form: a named marker type. It works for our own functions. It can't work for `fn main` or `#[tokio::main]`, because `Result<Done, E>` does not implement `Termination`. It also can't work for the many std and tokio APIs that return `io::Result<()>`.

```rust
/// Proof that an action finished and had nothing to report.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Done {}

pub async fn send_user(&self, text: String) -> Result<Done, Error> {
    self.request(|reply| CommandMsg::SendUser { text, reply }).await?
}

pub async fn interrupt(&self) -> Result<Done, Error> {
    self.control(ControlCall::Interrupt).await.map(|_| Done {})
}

async fn write(&mut self, msg: Outbound) -> Result<Done, Error> {
    let running = self.running()?;
    let line = encode(msg)?;
    running.stdin.write_all(line.as_bytes()).await.map_err(Error::Io)?;
    running.stdin.flush().await.map_err(Error::Io)?;
    Ok(Done {})
}

fn main() -> Result<Done, anyhow::Error> {
    tokio::runtime::Runtime::new()?.block_on(run())
}
```

## After
```rust
pub async fn send_user(&self, text: String) -> Result<(), Error> {
    self.request(|reply| CommandMsg::SendUser { text, reply }).await?
}

pub async fn interrupt(&self) -> Result<(), Error> {
    self.control(ControlCall::Interrupt).await.map(drop)
}

async fn write(&mut self, msg: Outbound) -> Result<(), Error> {
    let running = self.running()?;
    let line = encode(msg)?;
    running.stdin.write_all(line.as_bytes()).await.map_err(Error::Io)?;
    running.stdin.flush().await.map_err(Error::Io)
}

fn main() -> Result<(), anyhow::Error> {
    tokio::runtime::Runtime::new()?.block_on(run())
}
```

## Qualities
1. Named states: kept. `()` is a type with one value. There is nothing to decode.
2. Visible branching: kept.
3. Forward data flow: kept.
4. Errors are values: kept, and helped. `Result<(), E>` is the standard failure-only result, and `?` works through it.
5. Local reasoning: kept.
6. One way: kept. One marker for "nothing to report", the one std uses.
