# Review: `crates/agents` and `crates/proto` under subset v4 (v4fix)

The reviewer's pass over `74713a0` (`git diff main...rv-v4fix`, four commits from the merge base `f86c572`) and the implementer's five friction points, under subset version 4. Quality 7, "Repetition is data", is applied although `docs/subset.md` doesn't list it yet. The scratch files for every measurement are in `docs/subset/measurements/v4-agents-proto/`. Rerun any of them with `./target/debug/subset measure <file>`.

## Compliance

`subset check` reports nothing under `crates/agents/` or `crates/proto/`. The workspace has 603 violations, all in crates not yet converted to v4. `cargo fmt --check`, `cargo clippy -p agents -p proto --all-targets -- -D warnings`, `cargo clippy -p proto --target wasm32-unknown-unknown -- -D warnings` and `cargo test -p agents -p proto` (34 and 10 tests) pass. `cargo check --workspace --all-targets` passes, so the `DEFAULT_STUN_SERVERS` change to `&[&str]` doesn't break `client` or `daemon`. Agents measures 26,022 tokens and 4,364 lines. Proto measures 3,710 tokens and 598 lines.

The diff applies v4 correctly in most places. Every discard that was `drop(..)` or `.ok();` is now `let _ =`. The counting `fold`s are `filter(|v| matches!(..)).count()`. Both const lists are `&[T]`. Both handles route their round trips through one `ask<T>` whose closure only builds the variant. s2's turn records change in place under widened 0008, called on a value that `Run.turns` owns. Proto's only change is the const list, and it holds all seven qualities.

The verdict is **not yet compliant**. Five required fixes follow. Fixes 1 to 3 are introduced or left by this diff. Fixes 4 and 5 are carried from `main` and become breaches under quality 7. All five together are applied in a scratch worktree as `required-fixes.diff`. With them, clippy, the 34 agents tests and `subset check` pass, and the crate goes from 26,022 to 25,807 tokens (-0.8%).

### Required fixes

1. **Local reasoning and errors are values: s2 skips a turn that can't be missing.** `crates/agents/src/bin/s2.rs:224-226` writes `if let Some(turn) = self.turns.get_mut(&thread) { turn.record(event); }`, and `s2.rs:262-264` puts `Some(turn)` into `after_output`'s pattern. Both lookups follow a `get(..)?` at `s2.rs:213` that already failed if the turn was missing. The `if let` tells the reader that a missing turn needs nothing, which 0027 reserves for cases that really need nothing. Here a missing turn would be a bug, and the code would drop the event in silence. Fix: `self.turns.get_mut(&thread).context(..)?.record(event)`, and `after_output` returns `Result<()>`, looks its turn up with `?`, and matches only `(Plan::InterruptOnFirstOutput, None)`. Measured on `on`, `react` and `after_output`: 459 to 470 tokens (+2.4%, `s2-lookup-before.rs` and `s2-lookup-after.rs`). This is friction 4.
2. **One way: a `match` with an `Ok(()) => {}` arm.** `crates/agents/src/codex/server.rs:437-442` nests `match self.write(Outbound::Initialized).await { Ok(()) => {} Err(e) => .. }` inside an `if let`. 0027 names exactly this shape as the one it replaces. Fix: move the inner case into `async fn initialized(&mut self)` with an `if let Err(e)`, and call it from the outer `if let`. Measured on `on_response`: 157 to 166 tokens (+5.7%, `chain-before.rs` and `chain-method.rs`). This is friction 2. The let-chain alternative is under "Ratchet".
3. **One way: `.map(drop)` is a second discard.** `crates/agents/src/claude/session.rs:196`, `:202`, `crates/agents/src/codex/server.rs:208` and `crates/agents/src/claude/protocol.rs:266` discard a value by passing `drop` to `map`. Revised 0025 makes `let _ =` the one way to discard and keeps `drop` only to release a resource early. The diff's own commit "Discard with `let _ =`" converted every `drop(..)` call but missed these four. The checker doesn't see them, because `drop` appears as a path, not a call. `.map(|_| ())` is no alternative, because `subset check` flags its `()` (`expr.unit`). Fix: `let _ = x?;` then `Ok(())`. Measured on the four functions: 213 to 229 tokens (+7.5%, `mapdrop-before.rs` and `mapdrop-strict.rs`).
4. **Repetition: two copies of the child-stop protocol.** `crates/agents/src/claude/session.rs:25` and `:282-300`, and `crates/agents/src/codex/server.rs:30` and `:266-284`, hold the same `EXIT_GRACE` and the same `Running::stop` body: close stdin, wait for the grace period, kill, wait. Fix: one `pub(crate) async fn stop(mut child: Child, stdin: ChildStdin) -> Exit` in a new `crates/agents/src/process.rs`, with each `Running::stop` destructuring and calling it. Measured: 266 to 242 tokens (-9%, `stop-before.rs` and `stop-after.rs`). Moving the whole `Running` struct and its stdin and stdout methods into the shared module was tried first. `subset check` rejects it, because `Running` sits two steps below the actor (`Actor` to `Process` to `Box<Running>`) and 0008's reach is one step.
5. **Repetition: two copies of the live checks' scaffolding.** `crates/agents/src/bin/s1.rs:234-303` and `crates/agents/src/bin/s2.rs:298-358` each define `Presence`, `presence`, `Verdict`, `report`, `log_path` and `fresh_scratch`. The `fresh_scratch` copies differ only in the `SCRATCH` path. Fix: one `pub mod live` in the agents library, with `fresh_scratch(scratch: &Path)`, used by both binaries. 0002 allows the `pub`, because each binary is another crate. Measured: 624 to 391 tokens (-37%, `scaffold-before.rs` and `scaffold-after.rs`). The cost is that the library's public API carries helpers that only the live checks use. If the owner would rather keep them out of the API, the alternative is to merge `s1` and `s2` into one binary with a provider argument. That alternative was not measured.

### Advisory, not required

- **Quality 7 and small test groups.** `claude/protocol.rs` has three `parse_line` tests that differ only in the line, the request id and the subtype. `tests/replay.rs:386-417` has two refusal tests of one shape. Written as a `const` table of named structs with a `why` field, the three `parse_line` cases grow from 138 to 166 tokens (+20%, `cases-before.rs` and `cases-after.rs`). The named struct that 0001 requires for a lasting table costs more than three small tests save. Quality 7 needs a floor before it reaches tests like these, for example "three or more places, or wherever the table is shorter". Until the owner sets one, these tests stay as they are.
- **Type-only repetition is out of reach.** The two actors' `run`, `next_input`, `on_input`, `write`, `emit`, `Process` and `Input`, and `codex/protocol.rs`'s `command_answer` and `file_change_answer`, differ only in types. Sharing them needs a generic struct and a trait definition, both outside the subset by design (local reasoning). `log_stderr` differs in values (provider name and level). `tracing`'s `target:` must be a constant, so a parameter can't carry it.
- **Equality on a plain value still uses §11's `.eq(..).then_some(..)`.** This happens at `bin/s1.rs:322`, `bin/s2.rs:544` and `tests/codex_replay.rs:204`. The diff moved the two `Option` sites to `.filter(|x| x == y)`, which is the right v4 form for an `Option`. For a plain value, `Some(&x).filter(..)` would be longer, so the two forms follow the input's shape and are not two idioms for one task. §11 asks the reviewer to treat repeated `then_some` as friction. Three sites is the count to watch.
- **Carried from the agents review:** s2's `running` counter beside `turns` (`s2.rs:172`), and `Option<Result<(), Error>>` stored in fields (`s1.rs:95`, `s2.rs:174` and `:275`). These are unchanged and still for the owner.

## Friction points

1. **0027's example fails clippy.** `if let Some(_) = self.open.remove(&id)` trips `clippy::redundant_pattern_matching`. The rest pattern `Some(..)` trips it too (checked in scratch), and `subset check` also flags it as `pat.rest`. **Decision:** the form for "act if present, ignore the value" is the payload's own pattern with its fields elided, `Some(Open { .. })`, as the implementer wrote. It also names what was present, which helps named states. A payload with no struct or tuple-struct pattern (a `String`, say) has no form yet. Log it as friction when one turns up. 0027's Before and After sections should be amended to `Some(Open { .. })`.
2. **A nested `if let` trips `collapsible_if`.** Confirmed in scratch. Three forms were measured on `on_response`. The current `match` is 157 tokens, a let-chain is 151 (-3.8%) and an extracted method is 166 (+5.7%). **Decision:** extract the inner case into a method named for its action (required fix 2). That keeps `if let` as the only one-case form, and no lint is switched off. The let-chain isn't proposed: it is one site, -3.8% is below the threshold, and the other four let-chains in the workspace (`client/src/link.rs:440`, `client/src/platform/rtc.rs:304`, `client/src/transcript.rs:37`, `daemon/src/rtc.rs:440`) chain a `let` with a boolean, which 0028 keeps out whatever happens to let-chains. Suggested addition to 0027's rule: "When an `if let` body would be only another `if let`, the inner one becomes a method named for what it does."
3. **`&pat` in filter closures.** `got != &&turn.id` at `s2.rs:216`. **Decision:** this is the intended form, not a checker gap. `pat.reference` isn't in `subset.toml`, and adding it would give two ways to line up reference depth (`|&got|` against `&&id`) for one site in the workspace. `docs/subset.md`'s Branching row says `pat.*`, but `subset.toml` lists patterns one by one and leaves out `pat.reference` and `pat.rest`. The row should list them as the toml does.
4. **s2 looks up its turn twice.** **Decision:** this is a required fix (fix 1). The second lookup can't be removed while `react` needs `&mut self`, but its failure has to be a value, not a skipped branch.
5. **`drop(stdin)` in both `Running::stop`s.** **Decision:** this is the legitimate case under 0025. `stdin` is a named `ChildStdin`, dropping it closes the pipe, and the child exits on that EOF within `EXIT_GRACE` before the code falls back to a kill. That is a resource released before the end of its scope. After fix 4 it appears once, in `process::stop`.

## Spec and tool notes

- **0027's example.** As friction 1 says, its `Some(_)` fails clippy. Amend it to `Some(Open { .. })`.
- **`.map(drop)` in the checker.** `subset check` checks `drop(..)` calls but not `drop` passed as a function. Flag `drop` as a path argument, with 0025's message.
- **0008's reach is one step.** `Actor` to `Process` to `Box<Running>` is two steps, so a shared `Running` with `&mut self` methods is rejected (fix 4's first attempt). This is not friction yet, because sharing only `stop` is shorter. It is the first place the one-step limit has decided a design.
- **The `pat.*` row.** As friction 3 says, `docs/subset.md` overstates the allowed patterns.
- **Quality 7's floor.** See the advisory on small test groups.
